# Hindi News Shorts Bot (all free)
Secrets: GEMINI_API_KEY (required). Optional: ELEVENLABS_API_KEY, PEXELS_API_KEY, PIXABAY_API_KEY. Variable: CHANNEL_NAME.
Run: Actions > make-news-short > Run workflow. Video is in the run's Artifacts.
Voice chain: ElevenLabs (if key) > edge-tts > gTTS.

Automated IST scheduling via Google Apps Script: see [SETUP_APPS_SCRIPT.md](SETUP_APPS_SCRIPT.md).
